In progress, core unit built and live-tested: "Move" (the real Act)

Not an alpha blocker — separate track. Full spec: docs/guide/proposals/system-definition-synthesis.md Part 11 and docs/build/tier-1-build-and-operating-plan.md § Act / Move.

Design locked — 0-2 moves per round (not always exactly one), each a short scannable label + a full actionable prompt revealed on click, six explicit guardrail layers (four deterministic/airtight, two heuristic/pattern-based and documented as such), one sealed channel from Verify, item-level conditional-replace (untouched → replaced in place; touched → preserved, update becomes a separate item), whole-response rejection on any violation, no fallback repair anywhere. Core principle: the model proposes, policy constrains, the validator rejects, code never repairs, the user acts.

Built and live-tested: engine/src/act/ — types, policy, the six-layer validator, prompt construction, and one bounded live-call module. 38 hand-written fixtures, all passing. Ran a real, budget-tracked (50-call) evaluation: 7 hand-crafted adversarial cases plus 43 real fixtures (your own history + Chatbot Arena + SWE-chat). Found and fixed one real bug the eval surfaced — a request-detection check was too strict about where in a sentence the request-shaped verb had to appear, incorrectly rejecting a large share of otherwise-good real output; fixed and reverified for free (no model call needed) against both the failing real phrasings and the existing locked test cases.

Still not done: no persistence tables, no connector/UI wiring, no re-confirmation run of the real 0/1/2 distribution with the fix in place (needs a fresh, smaller budget authorization) — engine 329/237/0/92, typecheck clean, nothing wired into any product path yet.

Explicitly not a gate, for either target

SOC 2/ISO/enterprise SSO, CAPTURE-grade retention/correction/decision-record features, broad PDF/document-class support (before the locator design is sound), a polished marketing rebrand. Rule: scope the promise to the controls actually operated — not indefinite deferral, not invisible scope creep either.
