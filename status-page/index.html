Designed, not built: "Advance" (the real Track 2)

Not an alpha blocker. Full spec: docs/guide/proposals/system-definition-synthesis.md Part 11 and docs/build/tier-1-build-and-operating-plan.md § Track 2 / Advance.

Design is locked — four moves (Clarify/Test/Compare/Repair), one sealed channel from Track 1, conditional-replace-with-fallback (untouched suggestion is replaced in place with a new version; touched suggestion is preserved and the update becomes a separate item), zero-fallback validation (bad output → no suggestion, never a guess). Zero code exists. Build order, corrected: task-state schema → policy table → strict validator → fixtures against frozen real examples — then, only then, one bounded live model call. Don't let the database shape or a live model call get ahead of the fixtures.

Explicitly not a gate, for either target

SOC 2/ISO/enterprise SSO, CAPTURE-grade retention/correction/decision-record features, broad PDF/document-class support (before the locator design is sound), a polished marketing rebrand. Rule: scope the promise to the controls actually operated — not indefinite deferral, not invisible scope creep either.
