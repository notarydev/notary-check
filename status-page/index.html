Two release targets

Private alpha is a paid product launch to a deliberately small cohort — not an internal prototype with invited testers. It proves the full customer journey (discover → pay → use → get support) is real, just narrow. Public beta proves Notary can safely operate as open self-serve SaaS at scale. Neither blocks the other's own scope — alpha doesn't inherit beta's release machinery, beta doesn't wait on alpha's polish.

Proposed, not a build target: "Advance" (Track 2 v2)

Full design: docs/guide/proposals/system-definition-synthesis.md Part 11. Track 2 v1 above (§B, shipped dark) is unchanged by this — Advance is a distinct, larger feature, not v1.1: it works per-invocation instead of per-claim, starts concurrent with Track 1 instead of after it, and — when Track 1 later finds something material — adds a second, separate suggestion rather than mutating the first.

Gated on, in order: (1) an offline evaluation built from real, rights-cleared coding-agent transcripts (SWE-chat, SWE-Together) plus the user's own historical non-coding transcripts — explicitly not synthetic traces — each snapshot labeled with the real next action taken and, separately, an independent outcome judgment; (2) a causal in-alpha A/B test (Claude alone vs. Claude + Advance), with the no-finding case and the Track-1-finding case reported separately, since the no-finding case's value is unproven and the honest fallback if it fails is Case-2-only.

Nothing here blocks or is blocked by alpha's current punch list. Do not start building the invocation/polling infrastructure without the evaluation above existing first.

Explicitly not a gate — for either target

  • SOC 2 Type II, ISO certifications, enterprise SSO/SAML, dedicated support tooling, full team administration.
  • CAPTURE-grade retention/legal hold, full correction/supersession workflow, decision-family packs, examiner portal, obligation registry, cross-party boundary records.
  • Broad PDF/document-class support, before the retained-payload/locator design (alpha item A) is sound.
  • A polished, broad marketing rebrand.

Rule: scope the promise to the controls actually operated, not "defer trust" indefinitely. If an item doesn't help alpha or beta's own scorecard, it's enterprise/CAPTURE work or a deliberate research item — not invisible "SaaS polish."
